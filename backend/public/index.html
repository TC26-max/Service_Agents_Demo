How it works (for engineers)

Provable retrieval-augmented generation: each question is embedded and cosine-ranked against a 36-passage knowledge base, fused with a keyword ranking via reciprocal rank fusion (hybrid search), and the model answers only from the top passages with citations, behind guardrails that were red-teamed and are gated in the repo. The Retrieval X-ray tab exposes the ranking layer directly, scores included, no generation. Stack: vanilla-JS front end, serverless API on Vercel (SSE streaming, fair-use limits, server-owned persona), Google Gemini (embeddings and chat), honest "not in the knowledge base" fallback. The same retriever module runs in the page and on the server.

"Nimbus" is a fictional company created for this demonstration. Questions and voice clips are sent to Google Gemini to write the answers, so please don't enter real personal or payment data.
